・ This structure is used when stating conjecture based on information
the speaker obtained through hearsay or reading. This does not
directly quote someone else's statement, so it can be used when
referring to information that is not definitive （as shown in andB）.
・Unlike function B below，らしい for this function can only be used at
the end of the sentence.
